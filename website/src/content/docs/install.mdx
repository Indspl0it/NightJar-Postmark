Before you start, check that your phone meets the [requirements](/NightJar-Postmark/requirements/).

## Get the APK

Download the APK from the [releases page](https://github.com/Indspl0it/NightJar-Postmark/releases/latest). Each release has
one APK, which contains both the app and the Xposed module. To build the APK yourself, see
[building](/NightJar-Postmark/dev/building/).

## Check the download

Every NightJar release is signed with the same release key. Before you install, check that the APK carries this
certificate:

```text
SHA-256: BA:4C:89:90:1C:27:D3:FB:D6:B1:24:84:2E:B8:0C:BA:A3:E8:D3:AB:E5:F2:A3:B0:69:25:AC:47:8F:1B:13:8A
```

- **On the phone:** paste the fingerprint into an app that checks APK signatures, for example AppVerifier, and
  select the downloaded APK.
- **On a computer:** run `apksigner` from the Android SDK build tools.

  ```sh
  apksigner verify --print-certs NightJar-0.5.1-release.apk
  ```

  The line with `certificate SHA-256 digest` must show `ba4c89901c27d3fbd6b124842eb80cbaa3e8d3abe5f2a3b06925ac478f1b138a`.

If the fingerprint is different, don't install the APK, and report it as described in the
[security policy](https://github.com/Indspl0it/NightJar-Postmark/blob/main/SECURITY.md).

The same key signs the APK on GitHub, in the LSPosed module repository and on F-Droid, so you can update from any of
them. A debug build that you made yourself has a different key, and Android won't install a release over it. Uninstall
the debug build first.

## Install and turn on the module

<Steps>

1. Install the NightJar APK.

2. Open Vector or LSPosed.

3. Turn on the NightJar module.

4. Select **Phone Services** (`com.android.phone`) as the module scope. Do not add other apps to the scope.

5. Reboot the phone.

6. Open NightJar. The setup screens check each step. See [first run](/NightJar-Postmark/first-run/).

</Steps>

:::note
Keep the app installed. Vector or LSPosed loads the module into the phone service each time the phone service starts,
and the module sends its events to the app.
:::

## Update NightJar

Install the new APK over the old one. NightJar keeps your rules, settings and recorded messages.

Reboot the phone after the update. The old module keeps running in the phone service until you reboot. If the
module is newer than the app, NightJar shows "Update the NightJar app".

## Turn off or uninstall NightJar

<Steps>

1. Open Vector or LSPosed.

2. Turn off the NightJar module.

3. Reboot the phone. The phone service now runs without NightJar.

4. To delete your data too, uninstall the NightJar app.

</Steps>

Settings > Data and storage > **Turn off NightJar** shows the same steps.

## If calls or messages stop working

<Steps>

1. Open Vector or LSPosed and turn off the NightJar module.

2. Reboot the phone.

3. Report the problem with the build fingerprint and a diagnostics file. See
   [troubleshooting](/NightJar-Postmark/help/troubleshooting/).

</Steps>

If the phone can't start, turn off Xposed modules with the safe mode or module controls of your root manager.
