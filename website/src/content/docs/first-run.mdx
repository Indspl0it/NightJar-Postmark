## 1. Welcome

The welcome screen asks "Curious to see hidden messages and want to block or quarantine them?" and shows three
examples:

- **Silent SMS**: pings that confirm your phone is on and on the network.
- **Settings pushes**: APN and proxy changes that can send your traffic elsewhere.
- **Location and SIM**: SUPL location requests and SIM data download.

A line at the bottom confirms that NightJar has no internet permission. Select **Start**.

## 2. Setup

The setup screen has four steps. NightJar marks each one **Done**, **Do this step**, **Next step** or **Not
started**, and shows **Checking…** while a check runs.

| Step | NightJar checks that | If the check fails |
|---|---|---|
| Root access | NightJar has root | Select **Grant root** and allow NightJar in your root manager. If you denied it, open your root manager, allow NightJar, then select **Check again**. |
| Vector or LSPosed | The Xposed framework is installed | Install Vector or LSPosed from your root manager. Then select **Check again**. |
| Turn on the module | The NightJar module is on, with the scope Phone Services | Select **Open LSPosed**. Turn on NightJar. Select Phone Services as the scope. |
| Reboot the phone | The module runs in the phone service | Select **Reboot phone**. NightJar keeps your messages and settings. |

Your root manager asks once for root access. NightJar uses root to find Vector or LSPosed, restart the phone service
and reboot the phone. It doesn't use root to read your messages.

If you select **Later** on the reboot step, reboot the phone from the power menu. If NightJar can't reboot the phone,
it shows the reason and you can select **Later** and use the power menu instead.

If the checks can't run at all, NightJar shows "NightJar cannot complete the checks. Select Check again."

## 3. Ready

After the reboot, NightJar shows **NightJar is active** and the SIMs it monitors. With the Recommended preset, it
adds "The Recommended preset is on." Two switches follow:

- **Notifications** (Suspicious messages only) shows whether NightJar may send notifications. Turn it on to give
  Android's notification permission. Turning it off opens the system notification settings.
- **Researcher mode** (Raw PDUs and decoder details) adds the researcher views to the app. It's off by default.

You can change both later in [Settings](/NightJar-Postmark/guide/settings/). Select **Open NightJar** to go to
[Home](/NightJar-Postmark/guide/home/).

## Optional self-test

The [self-test](/NightJar-Postmark/guide/self-test/) sends harmless test messages to the phone and checks that NightJar
recognises each message type. NightJar blocks each test message before an app receives it. Protection works without
the self-test.
