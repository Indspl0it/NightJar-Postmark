## Recording

NightJar works inside the SMS path of the phone service and records messages from these paths:

- SMS over the circuit-switched network (2G, 3G) and SMS over IMS (LTE, NR, Wi-Fi calling)
- WAP push messages, such as MMS notifications, settings pushes and location requests
- SIM data download, and messages the phone saves on the SIM
- Cell broadcasts, including emergency alerts
- Voicemail indicators and visual voicemail control messages
- Delivery reports
- Messages that apps on the phone or the SIM send

For each message, NightJar records the type, the sender, the SIM, the port, the PDU and what Android did with it, for
example "Shown in Messages", "Sent to the SIM card" or "NightJar blocked it".

NightJar counts the regular texts your messaging app shows but doesn't store them.

Each message has a detail screen with these sections:

| Section | Contents |
|---|---|
| What this is | A plain explanation of the type |
| Why NightJar marks this as suspicious, or Why NightJar flagged it | The patterns a detector found |
| Evidence | The protocol identifier, data coding, port and service centre |
| Anomalies | Format errors in the PDU |
| What happened | Each step the message took through the phone service |
| Raw PDU | Researcher mode only. The bytes in hex, the decoded fields and the pipeline trace. |

## Hold or block by type

On the [Protection](/NightJar-Postmark/guide/protection/) tab, you select **Allow**, **Hold** or **Block** for each message
type, or pick a preset: Monitor, Recommended, Strict or Quarantine. After you change a single type, the preset shows
as Custom.

A held message stays in NightJar, and no other app receives it. If you release it, Android delivers it as a new
message. A blocked message never reaches an app.

## Custom rules

A [custom rule](/NightJar-Postmark/guide/custom-rules/) matches on the type, sender, SIM, port, content type, service centre,
roaming state and text. Custom rules run before the preset, so you can make an exception for one sender.

## Detectors

[Detectors](/NightJar-Postmark/features/detection/) look for known attack patterns, for example:

- A burst of silent SMS
- A settings push without a network PIN
- A command to the SIM browser
- A SIM that sends a message after an update

## Notifications

NightJar notifies you about suspicious messages. A notification has up to three actions: **Open**, **Allow** and
**Block**. A weekly summary counts what arrived. See
[notifications](/NightJar-Postmark/guide/notifications/).

## Protection status and self-test

The [Protection status](/NightJar-Postmark/guide/protection-status/) screen shows the state of each hook, the module version,
the rules the phone service holds and the result of the last self-test. The [self-test](/NightJar-Postmark/guide/self-test/)
sends harmless test messages and checks that NightJar recognises each one.

## Export and diagnostics

You can [export](/NightJar-Postmark/guide/export/) messages as JSON, CSV or PDU hex. By default, the export leaves out message text,
and you can also mask phone numbers. To report a problem, attach a diagnostics file.

## Privacy

NightJar has no internet permission and keeps its data in an encrypted database on the phone. See
[privacy](/NightJar-Postmark/safety/privacy/).
